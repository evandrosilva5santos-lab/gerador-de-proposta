Design System
START Proposta

O sistema visual das propostas comerciais da START INC. Salve, reutilize e mantenha consistência em toda proposta — capa, escopo, bonificações, investimento e depoimentos. Alterne entre o tema dark/neon e o tema START claro no menu ao lado.

Fundamentos

Cores
A base é escura e profunda; o brilho vem dos gradientes e do verde de destaque. Use os neutros para superfícies e texto, e reserve os vivos para ação e ênfase.
